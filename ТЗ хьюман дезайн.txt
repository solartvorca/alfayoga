ТЗ: Квест Человеческого Дизайна

Страница: hd.html — "Человеческий Дизайн"

Доступ: все авторизованные участники марафона

Уровни и условия разблокировки:

Уровень	Условие	Содержание
1	29+ лучиков	Тип, Стратегия, Авторитет
2	58+ лучиков	Профиль, Центры, Каналы
3.1 / 3.2 / 3.3	10 рефералов открыли уровень 1, либо premium-подписка	Специалистский уровень
Структура каждого уровня:

Пользователь видит карточку уровня — заблокирована или открыта
Внутри: кнопка "Получить свой чарт" → внешний сервис в новой вкладке
Форма ввода своих данных (тип, профиль, ворота и т.д. по теме уровня)
После сохранения → Царь генерирует персональную расшифровку на основе базы знаний
Расшифровка сохраняется в профиль, при повторном входе показывается готовая
База знаний (admin.html → новая вкладка "HD База"):

Коллекция Firestore: hd_knowledge

Документы по темам:


hd_knowledge/types       → тексты по каждому типу (Generator, Projector...)
hd_knowledge/profiles    → по каждому профилю (1/3, 2/4...)
hd_knowledge/authorities → по каждому авторитету
hd_knowledge/centers     → по каждому центру
hd_knowledge/channels    → по каждому каналу
hd_knowledge/gates       → по воротам
Каждый документ: { title, content, level } — админ добавляет/редактирует через форму.

BodyGraph:

Кнопка "Загрузить мою карту" — загружает изображение в Firebase Storage
URL сохраняется в users/{uid}.hdChartUrl
Отображается в профиле пользователя
Firestore — данные пользователя:


users/{uid}.hdData: {
  level: 1,                        // открытый уровень
  type: "Generator",
  strategy: "...",
  authority: "Sacral",
  profile: "2/4",
  definedCenters: ["Sacral", ...],
  channels: ["25-51", ...],
  gates: [...],
  cross: "...",
  aiReadings: {                    // сохранённые расшифровки Царя
    level1: "...",
    level2: "...",
    level3: "..."
  }
}
Царь + база знаний:

При запросе расшифровки:

Читаем нужный раздел из hd_knowledge (по теме уровня)
Передаём в промпт: [база знаний] + [данные пользователя]
Царь пишет персональный текст
Сохраняем в hdData.aiReadings
