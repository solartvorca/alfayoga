🤖 Настройки ИИ (OpenRouter)

Модель выбирается автоматически из топовых бесплатных: Gemini 2.0, LLaMA 3.3, Qwen 2.5 и др.

✓ Настройки сохранены
🎨 Gemini API (генерация изображений)

Ключ из aistudio.google.com — используется для генерации изображений юпика через Imagen 3.

🎨 Pollinations.ai (генерация юпиков)

Бесплатный сервис без ключа. Используется для генерации изображений юпика по лучикам участника. Нажми Тест чтобы увидеть пример.

ℹ️ Как работает ИИ

• После каждого нового отчёта — ИИ пишет добрый комментарий

• После каждого комментария участника — ИИ реагирует

• При смене лунного дня — ИИ публикует отчёт о задании с научным исследованием

• На странице "И Цзин" — ИИ толкует выпавшую гексаграмму

Получить ключ: openrouter.ai/keys

🖼️ Очистка изображений сновидений
Удаляет поле imageBase64 из всех сновидений где дата картинки не сегодня. Запускай раз в несколько дней чтобы не засорять базу.
📖 Словарь предназначений

Словарь используется для поиска слов, скрытых в буквах ФИО участника. ИИ Царь строит послание о предназначении из найденных слов.
Введи слова через запятую, пробел или по одному на строке. Регистр не важен.
